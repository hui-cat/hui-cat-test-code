

## 第一章：动态规划 (DP) 基础

### 1.1 什么是动态规划？
动态规划（Dynamic Programming）是一种通过把原问题分解为相对简单的子问题，并保存子问题的解来避免重复计算，从而解决复杂问题的算法思想。

### 1.2 DP 的三大核心要素
1. **状态定义**：用一个数组（一维或二维）及其下标来抽象表示当前面临的局面。
2. **状态转移方程**：当前状态如何由之前的状态推导而来（递推公式）。
3. **边界条件**：最小的子问题（初始状态）是什么。

### 1.3 经典案例：数字金字塔
*   **题目大意**：从金字塔顶点走到底部，求路径数字之和的最大值。每次只能向左下或右下走。
*   **解法一：自顶向下（DFS式 DP）**
    *   **状态定义**：`dp[i][j]` 表示从顶点走到 `(i,j)` 的最大和。
    *   **转移方程**：`dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + val[i][j]`
    *   **注意**：需要处理左边界（无左上方）和右边界（无正上方）。
*   **解法二：自底向上（推荐）**
    *   **状态定义**：`dp[i][j]` 表示从底部走到 `(i,j)` 的最大和。
    *   **转移方程**：`dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + val[i][j]`
    *   **优势**：无需处理边界条件，代码极简，最终答案即 `dp[0][0]`。

## 第二章：线性 DP 进阶 —— 最长上升子序列 (LIS)

### 2.1 问题模型
给定一个序列，求其最长严格上升（或非降、不升等）子序列的长度。

### 2.2 基础解法：\(O(n^2)\) 动态规划
*   **状态定义**：`dp[i]` 表示以第 `i` 个元素结尾的最长上升子序列长度。
*   **转移方程**：遍历 `j < i`，如果满足条件（如 `a[j] < a[i]`），则 `dp[i] = max(dp[i], dp[j] + 1)`。
*   **初始化**：所有 `dp[i] = 1`（自身也算长度1）。

### 2.3 进阶解法：贪心 + 二分查找 \(O(n \log n)\)
**核心思想**：维护一个 `tail` 数组，`tail[i]` 表示长度为 `i+1` 的上升子序列中，**末尾元素的最小值**。
*   **贪心策略**：末尾元素越小，后续接上更大数字的“潜力”就越大。
*   **二分查找**：`tail` 数组天然保持递增有序，因此可以用二分查找寻找替换位置。

#### STL 工具：`lower_bound` 与 `upper_bound`
前提：容器区间必须是有序的（默认升序）。
*   `lower_bound(begin, end, x)`：查找第一个 **大于等于** `x` 的元素位置。
*   `upper_bound(begin, end, x)`：查找第一个 **严格大于** `x` 的元素位置。
*   *自定义谓词*：传入 `greater<int>()` 可作用于降序数组，此时 `lower_bound` 寻找第一个 **小于等于** `x` 的位置。

#### 边界条件与组合应用
*   **最长严格上升**：遇到相等的不能接，替换第一个 `>= x` 的位置 \(\rightarrow\) `lower_bound`
*   **最长不下降**：遇到相等的可以接，替换第一个 `> x` 的位置 \(\rightarrow\) `upper_bound`
*   **最长严格下降**：将数组反转，求最长严格上升（`lower_bound`）。
*   **最长不上升**：将数组反转求最长不下降（`upper_bound`），或对原数组用 `lower_bound(..., greater<int>())`。

### 2.4 Dilworth 定理
*   **定理内容**：在一个偏序集中，最小链的划分数等于最大反链的大小。
*   **算法应用**：求“最少的不上升子序列个数”等价于求“**最长严格上升子序列的长度**”。（拦截导弹问题）

## 第三章：二维 DP —— 最长公共子序列 (LCS)

### 3.1 问题模型
给定两个序列 \(X\) 和 \(Y\)，求它们的最长公共子序列（不要求连续，但要求顺序一致）的长度。

### 3.2 为什么不能用贪心？
贪心算法（如LIS的替换法）具有局限性。局部的最优替换可能会破坏之前已经建立好的匹配关系，导致后续字符无法匹配。

### 3.3 二维 DP 解法
*   **状态定义**：`dp[i][j]` 表示序列 \(X\) 的前 `i` 个字符，与序列 \(Y\) 的前 `j` 个字符，所能构成的最长公共子序列长度。
*   **状态转移方程**：
    *   如果 `X[i-1] == Y[j-1]` （当前字符相等）：`dp[i][j] = dp[i-1][j-1] + 1`
    *   如果 `X[i-1] != Y[j-1]` （当前字符不相等，丢车保帅）：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
*   **边界条件**：`dp[0][j] = 0` 且 `dp[i][0] = 0`。为了处理边界，通常开大小为 `(n+1) x (m+1)` 的数组，从 `1` 开始遍历。
*   **最终答案**：`dp[n][m]`。

## 第四章：DP 代码规范与优化技巧

### 4.1 空间压缩（滚动数组）
*   **二维 LCS 压缩到一维**：由于 `dp[i][j]` 只依赖于 `dp[i-1][j-1]`、`dp[i-1][j]` 和 `dp[i][j-1]`，可以仅保留一行空间。**注意：内层循环 `j` 必须从后往前遍历**，否则会覆盖下一轮循环所需的左上角数据（`dp[i-1][j-1]`）。
*   **`vector` 优化**：使用 `vector.reserve()` 提前预分配内存，避免动态扩容的性能损耗。

### 4.2 输入输出加速（C++）
在数据量大时，使用 `cin / cout` 容易超时，需加入以下代码：
```cpp
ios::sync_with_stdio(0);
cin.tie(0);
```

### 4.3 类型安全与细节
*   `vector<bool>` 底层是按位存储，并非标准容器，不建议使用，建议替换为 `vector<char>` 或 `vector<int>`。
*   `container.size()` 返回的是无符号整数 `size_t`，与有符号 `int` 进行比较时编译器会报警告。建议先转存：`int n = a.size();`。
*   使用 `max_element` 时，注意返回的是迭代器/指针，输出数值需加解引用符 `*`；同时注意区间只遍历有效部分 `max_element(dp, dp + n)`，而非整个大数组。
