

> **核心概念**：栈（Stack）是一种**后进先出（LIFO, Last In First Out）**的数据结构。只能在一端（栈顶）进行插入和删除操作。
> **头文件**：`#include <stack>`
> **底层结构**：默认基于 `deque`（双端队列）实现，也可指定基于 `vector` 或 `list`。

## 一、 核心成员函数

`stack` 的操作非常精简，只有以下几个核心接口：

| 函数 | 功能 | 时间复杂度 | 注意事项 |
| :--- | :--- | :--- | :--- |
| `push(x)` | 将元素 `x` 压入栈顶 | $O(1)$ | 无返回值 |
| `pop()` | 弹出栈顶元素 | $O(1)$ | **不返回元素值**，只是删除 |
| `top()` | 获取栈顶元素的引用 | $O(1)$ | 必须是**非空栈** |
| `empty()` | 判断栈是否为空 | $O(1)$ | 返回 `bool` |
| `size()` | 返回栈中元素个数 | $O(1)$ | 返回 `size_t`（无符号整数） |

## 二、 基础用法示例

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> stk;
    
    // 1. 入栈
    stk.push(10);
    stk.push(20);
    stk.push(30); // 此时栈顶是 30
    
    // 2. 获取大小
    cout << "栈的大小: " << stk.size() << endl; // 输出 3
    
    // 3. 访问栈顶（注意：必须先判空！）
    if (!stk.empty()) {
        cout << "栈顶元素: " << stk.top() << endl; // 输出 30
    }
    
    // 4. 出栈（后进先出）
    stk.pop(); // 弹出 30，此时栈顶变成 20
    cout << "弹出后栈顶: " << stk.top() << endl; // 输出 20
    
    // 5. 清空栈
    while (!stk.empty()) {
        stk.pop();
    }
    cout << "栈是否为空: " << (stk.empty() ? "是" : "否") << endl; // 输出 是
    
    return 0;
}
```

## 三、 重要特性与限制

1. **没有迭代器（Iterator）**：
   `stack` 不提供 `begin()`、`end()`，这意味着**无法使用范围 for 循环（`for(auto x : stk)`）**，也无法使用 `sort`、`reverse` 等 STL 算法。如果要遍历栈，唯一的方法就是不断 `top()` 和 `pop()`，但这会破坏栈的结构。
2. **不支持随机访问**：
   不能使用 `stk[i]` 访问元素。栈是一种受限的线性表。
3. **没有 `clear()` 方法**：
   `stack` 没有提供 `clear()` 函数。想要清空栈，必须循环 `pop()`，或者直接重新赋值 `stk = stack<int>();`。
4. **`emplace()` 代替 `push()`**：
   C++11 起提供了 `emplace()`，可以直接在栈顶原地构造元素，避免临时对象的拷贝开销。对于基本数据类型，和 `push()` 几乎一样；对于结构体，`stk.emplace(args...)` 比 `stk.push(Type(args...))` 更高效。

## 四、 OJ 实战典型场景

### 场景 1：括号匹配（你刚做完的 DS1012）
*   **思路**：遇到左括号压栈，遇到右括号检查栈顶是否匹配。匹配则 `pop`，不匹配或栈空则判定失败。
*   **关键代码**：
    ```cpp
    if (stk.empty() || stk.top() != '(') { isGood = false; break; }
    stk.pop();
    ```

### 场景 2：单调栈（求下一个更大/更小元素）
*   **思路**：栈中存储下标，维护栈内元素的单调性。常用于 $O(N)$ 解决“找左边/右边第一个比它大/小的数”的问题。
*   **关键代码**：
    ```cpp
    while (!stk.empty() && nums[stk.top()] < nums[i]) {
        // 当前元素 i 就是栈顶元素右侧第一个更大的数
        ans[stk.top()] = nums[i];
        stk.pop();
    }
    stk.push(i);
    ```

### 场景 3：表达式求值（中缀转后缀 / 后缀求值）
*   **思路**：使用两个栈，一个存操作数，一个存运算符。或者将中缀表达式转为后缀表达式，再用一个栈求值。

### 场景 4：深度优先搜索（DFS）的迭代写法
*   **思路**：递归的本质就是系统在底层帮你维护了一个函数调用栈。为了防爆栈，可以使用 `stack` 手动模拟 DFS 的访问过程。

## 五、 ⚠️ 避坑指南（血泪经验）

1. **空栈调用 `top()` 或 `pop()` 会导致段错误（RE）**：
   这是新手写栈代码最容易犯的错误（你刚踩过的坑）。**任何 `top()` 和 `pop()` 操作，之前必须加 `if (!stk.empty())` 判断！**
2. **`pop()` 不返回值**：
   不要在 `cout` 里直接写 `stk.pop()`，编译器会报错。必须先 `stk.top()` 取值，再 `stk.pop()` 删除。
3. **`size()` 的无符号陷阱**：
   `stk.size()` 返回 `size_t`。如果写 `for (int i = 0; i <= stk.size() - 1; i++)`，当栈为空时，`0 - 1` 会变成极大的正数，导致死循环。推荐用 `while (!stk.empty())` 遍历。
4. **结构体比较与重载**：
   如果 `stack` 存的是自定义结构体，并且你用了 `stk.top() != '('` 这种比较，需要确保结构体重载了 `==` 和 `!=` 运算符，否则编译报错。
5. **清空栈的最佳实践**：
   如果要在多组测试数据间复用栈，记得在每组数据开头清空：`while(!stk.empty()) stk.pop();` 或 `stk = stack<int>();`。

## 六、 配套的 `queue` 速览（易混淆点）

`stack`（栈）和 `queue`（队列）都是容器适配器，接口非常相似，但核心区别在于**访问端**：
*   **`stack`**：后进先出。用 `top()` 访问栈顶。
*   **`queue`**：先进先出。用 `front()` 访问队首，`back()` 访问队尾。**`queue` 没有 `top()` 函数，千万别写错！**
