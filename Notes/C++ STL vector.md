# 📘 C++ STL：`vector` 容器完全指南

## 一、 核心概念：什么是 `vector`？
`vector` 是 C++ 标准模板库（STL）中最常用的**动态数组**。它在**堆内存**中分配空间，能够自动扩容，并且保证元素在内存中的**连续存储**。
*   **优势**：支持随机访问（$O(1)$），尾部插入/删除效率高（均摊 $O(1)$），自动管理内存（无需手动 `new/delete`）。
*   **劣势**：中间或头部插入/删除效率低（需要挪动后续所有元素，$O(n)$），扩容时会产生性能开销。

## 二、 初始化方式
```cpp
#include <vector>
#include <iostream>
using namespace std;

int main() {
    // 1. 默认初始化：空的 vector
    vector<int> v1; 

    // 2. 指定大小并初始化（默认值为 0）
    vector<int> v2(5);        // 包含 5 个元素，均为 0

    // 3. 指定大小和初始值
    vector<int> v3(5, 10);    // 包含 5 个元素，均为 10

    // 4. 列表初始化（C++11 特性）
    vector<int> v4 = {1, 2, 3, 4, 5};

    // 5. 从数组或其他容器拷贝初始化
    int arr[] = {1, 2, 3};
    vector<int> v5(arr, arr + 3);  // 复制数组 arr 的前 3 个元素

    // 6. 二维 vector 初始化
    vector<vector<int>> v2d(3, vector<int>(4, 0)); // 3行4列，全为 0

    return 0;
}
```

## 三、 核心成员函数详解

### 1. 容量与大小
*   **`size()`**：返回当前容器中实际存放的**元素个数**。返回类型是 `size_t`（无符号整数）。
*   **`capacity()`**：返回当前容器在不重新分配内存的情况下，**最多能容纳的元素个数**。
    *   *区别*：`size` 是实际住客，`capacity` 是房子总面积。
    *   *扩容机制*：当 `size == capacity` 时，再插入元素会触发扩容。系统通常会申请一块原容量 **1.5 倍或 2 倍**的新内存，将旧数据搬过去，再释放旧内存。
*   **`empty()`**：判断容器是否为空，返回 `bool`。`empty()` 比 `size() == 0` 更高效（在底层实现上）。

### 2. 元素访问
*   **`at(index)`**：**带边界检查**的访问。如果 `index` 越界，会抛出 `std::out_of_range` 异常（程序可捕获并处理）。
*   **`v[index]`**：**不带边界检查**的数组式访问。越界是未定义行为（UB），极大概率导致程序崩溃或灵异Bug。
*   **`front()`**：返回第一个元素的引用。
*   **`back()`**：返回最后一个元素的引用。**⚠️ 对空 `vector` 调用 `back()` 是未定义行为！**
*   **`data()`**：返回指向底层数组的指针（C++11）。

### 3. 修改操作
*   **`push_back(val)`**：在尾部添加一个元素。这是 `vector` 最常用的操作。
*   **`pop_back()`**：删除尾部的一个元素。
*   **`clear()`**：清空所有元素，`size` 变为 0，但 **`capacity` 不变**。
*   **`insert(pos, val)`**：在迭代器 `pos` 指定的位置插入元素（效率低，慎用）。
*   **`erase(pos)`**：删除迭代器 `pos` 指定的元素（效率低，慎用）。
*   **`reserve(n)`**：**预分配内存**，将 `capacity` 设为 `n`。如果已知数据量很大，提前 `reserve` 可以避免频繁扩容，极大提升性能。
*   **`resize(n, val)`**：改变 `size` 为 `n`。如果 `n` 比当前大，多出的部分用 `val` 填充；如果 `n` 比当前小，多余部分被截断。

### 4. 迭代器
*   **`begin()`**：返回指向第一个元素的迭代器（类似指针）。
*   **`end()`**：返回指向**最后一个元素的下一个位置**的迭代器（左闭右开区间 `[begin, end)`）。
*   *注意*：`end()` 不指向任何实际元素，不能解引用 `*end()`。
*   *用法示例*：
    ```cpp
    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << *it << " ";
    }
    ```

## 四、 具体使用场景

### 1. 算法竞赛（OJ）场景
*   **图的邻接表**：`vector<int> adj[N+1];` 存储图的边，无需提前知道每个点的度数。
*   **动态规划（DP）**：当状态转移需要依赖上一行时，可以用 `vector` 动态分配空间。
*   **去重/排序**：配合 `sort(v.begin(), v.end())` 和 `v.erase(unique(v.begin(), v.end()), v.end())` 实现数组去重。
*   **模拟栈/队列**：虽然 STL 有 `stack` 和 `queue`，但有些题目需要随机访问时，仍用 `vector` 模拟。

### 2. 游戏开发（Unity / C# 迁移）场景
C++ 的 `vector` 与 C# 中的 `List<T>` 几乎完全对应（两者都是动态数组）。学好 `vector`，未来你写 Unity C# 脚本时会无缝衔接：
*   **背包系统**：`List<Item> inventory` 存储玩家动态拾取的物品。
*   **对象池（Object Pooling）**：`List<GameObject> bulletPool` 管理子弹等频繁生成/销毁的对象，避免频繁 GC（垃圾回收）。
*   **A*寻路算法**：OpenList（开放列表）通常用 `List<Node>` 或优先队列实现，用来存储待检查的节点。
*   **弹幕系统**：存储屏幕上所有存活弹幕的位置、速度等信息。

## 五、 ⚠️ 避坑指南与性能优化

1.  **`size_t` 的无符号陷阱**：
    `v.size()` 返回无符号整数。如果 `v` 为空，`v.size() - 1` 会变成一个巨大的正数（而不是 -1），导致循环越界崩溃。
    *   *正确写法*：`for (int i = 0; i < (int)v.size() - 1; i++)` 或者提前 `int len = v.size();`。
2.  **迭代器失效（Iterator Invalidation）**：
    当 `vector` 发生**扩容**时，原有的所有迭代器、指针、引用都会失效（因为内存地址变了）。在遍历中使用 `push_back` 极易引发崩溃。
3.  **内存不连续与缓存命中**：
    `vector` 本身是连续的，但在数组的数组中（`vector<vector<int>>`），行与行之间是不连续的。若追求极致的 CPU 缓存命中率（如高性能游戏引擎开发），建议用一维数组模拟二维（`vector<int> v(m * n)`）。
4.  **`at()` 与 `[]` 的选择**：
    *   在 OJ 比赛中，通常已知边界安全，为了性能，用 `v[i]`。
    *   在工程开发中，若无法确保索引绝对安全，用 `v.at(i)` 捕获异常更稳妥。
5.  **提前 `reserve`**：
    如果已知要 `push_back` 一万次，提前 `v.reserve(10000);` 可以避免多次扩容和数据拷贝，这是性能优化的常见手段。
6.  **`clear()` 不释放内存**：
    如果 `vector` 占用内存极大，`clear()` 后内存并不会还给操作系统。要想真正释放，可以使用 `vector<int>().swap(v);`（C++11 前的经典写法）或 `v.shrink_to_fit();`（C++11）。
