# 快速幂（Fast Exponentiation）详解与实战

## 快速幂（Fast Exponentiation）

在之前的星期计算题中，我们使用了循环 $O(b)$ 的时间复杂度。当 $b$ 达到 $10^8$ 或 $10^9$ 级别时，循环会严重超时（TLE）。快速幂能够将计算 $a^b$ 的时间复杂度从 $O(b)$ 降为 **$O(\log b)$**。

### 1. 核心原理：二进制拆分（二分思想）

计算 $a^b$ 时，我们可以利用指数的二进制表示来加速：
例如计算 $3^{13}$：
*   $13$ 的二进制是 `1101`（即 $8 + 4 + 1$）
*   $3^{13} = 3^8 \times 3^4 \times 3^1$
*   我们只需要计算 $3^1, 3^2, 3^4, 3^8$，每次将底数平方即可，只需循环 $O(\log b)$ 次（大约 30 次以内）。

结合取模运算，我们可以在每次平方和乘法时都进行 `% m`，防止数据溢出。

### 2. 具体代码实现

#### 模板一：迭代法（⭐ 最推荐，无递归栈溢出风险）

```cpp
// 计算 (a^b) % m
long long fastPow(long long a, long long b, long long m) {
    long long res = 1;
    a %= m; // 防止 a 本身过大
    while (b > 0) {
        if (b & 1) { // 如果当前二进制位为 1 (等价于 b % 2 == 1)
            res = (res * a) % m;
        }
        a = (a * a) % m; // 底数平方
        b >>= 1;         // 指数右移一位 (等价于 b /= 2)
    }
    return res;
}
```

#### 模板二：递归法（便于理解数学本质）

```cpp
// 计算 (a^b) % m 的递归版
long long fastPowRecursive(long long a, long long b, long long m) {
    if (b == 0) return 1;
    a %= m;
    long long half = fastPowRecursive(a, b / 2, m);
    if (b % 2 == 0) {
        return (half * half) % m;
    } else {
        return (half * half % m) * a % m;
    }
}
```

### 3. 结合 OJ 题目的实战改写

将快速幂应用到你的“星期几”题目中，只需将原来的 `for` 循环替换为一次快速幂调用即可：

```cpp
#include <iostream>
using namespace std;

// 快速幂模板
long long fastPow(long long a, long long b, long long m) {
    long long res = 1;
    a %= m;
    while (b > 0) {
        if (b & 1) res = (res * a) % m;
        a = (a * a) % m;
        b >>= 1;
    }
    return res;
}

int main() {
    long long a, b;
    cin >> a >> b;
    
    // 直接计算 a^b % 7，初始余数为 0（星期日）
    long long n = fastPow(a, b, 7); 
    
    switch(n) {
        case 0: cout << "Sunday" << endl; break;
        case 1: cout << "Monday" << endl; break;
        case 2: cout << "Tuesday" << endl; break;
        case 3: cout << "Wednesday" << endl; break;
        case 4: cout << "Thursday" << endl; break;
        case 5: cout << "Friday" << endl; break;
        case 6: cout << "Saturday" << endl; break;
    }
    return 0;
}
```

### 4. 使用场景

1.  **超大指数取模**：OJ 中求 $a^b \pmod m$，且 $b \ge 10^8$ 时的唯一正解。
2.  **密码学（RSA 算法）**：RSA 加密和解密过程中需要计算巨大的指数取模（如 $c = m^e \pmod n$），快速幂是其底层核心。
3.  **斐波那契数列（矩阵快速幂）**：求斐波那契数列第 $10^{18}$ 项时，可以将递推式转化为矩阵乘法，再用快速幂加速。
4.  **游戏开发中的伪随机数**：线性同余发生器（LCG）及部分随机种子生成算法中，会用到乘法和取模操作。

### 5. ⚠️ 避坑指南（竞赛与开发通用）

1.  **必须使用 `long long`**：即使输入数据在 `int` 范围内，但在快速幂的平方步骤（`a = a * a % m`）中，`a * a` 极易超过 `int` 的 21 亿上限。请务必使用 `long long` 作为参数和返回值类型。
2.  **特殊值的处理**：
    *   如果 `b = 0`，快速幂返回 `1`（任何非零数的 0 次方为 1）。注意 $0^0$ 在数学上未定义，需根据题目要求特判。
    *   如果 `m = 1`，结果永远是 `0`，直接在函数开头 `return 0;` 可以节省时间。
3.  **位运算的优先级**：`b & 1` 必须加括号写成 `(b & 1)`，因为 `&` 的优先级比 `==` 和 `>` 低，不加括号容易产生逻辑错误。
4.  **递归 vs 迭代**：在实际 OJ 提交中，**永远优先使用迭代版**。当指数 $b$ 极大时，递归深度达到 $\log_2(10^{18}) \approx 60$ 层，虽然安全，但递归函数的调用开销在极致卡常的题目中不划算。
