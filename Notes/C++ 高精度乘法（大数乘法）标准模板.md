# 📘 C++ 算法竞赛：高精度乘法（大数乘法）标准模板

> **适用场景**：OJ 中处理两个超大整数（超过 200 位，超过 `long long` 范围）的乘法运算。
> **核心思想**：模拟小学列竖式乘法，利用双重循环和位置映射，最后统一处理进位。

## 一、 核心数学原理

假设有两个大整数 $a = 123$ 和 $b = 45$。在列竖式计算时，是用 $b$ 的每一位去乘 $a$ 的每一位：
*   个位：$5 \times 3 = 15$（放在结果下标 $0 + 0 = 0$ 的位置）
*   十位：$5 \times 2 = 10$（放在结果下标 $0 + 1 = 1$ 的位置）
*   百位：$5 \times 1 = 5$（放在结果下标 $0 + 2 = 2$ 的位置）
*   接着用 $4$ 去乘 $a$ 的每一位，放在下标 $1 + 0, 1 + 1, 1 + 2$ 的位置……

**核心公式**：
对于 $a$ 的第 $i$ 位和 $b$ 的第 $j$ 位（均从低位起），它们相乘时，会对最终结果的第 $i+j$ 位产生贡献：
`res[i + j] += (a[i] - '0') * (b[j] - '0')`

最后，再统一处理结果的进位问题。

## 二、 标准代码模板（C++ STL string 版）

使用 `vector<int>` 存储中间结果，避免了字符串频繁拼接和反转的开销。

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

// 高精度乘法函数：返回 a * b 的字符串结果
string multiply(string a, string b) {
    // 特判 0，防止后续去前导零时返回空字符串
    if (a == "0" || b == "0") return "0"; 
    
    int m = a.size(), n = b.size();
    // 结果为逆序存储（低位在 vector 头部）
    // 两个数相乘，结果最大位数为 m + n
    vector<int> res(m + n, 0); 
    
    // 1. 翻转字符串，让个位在下标 0 处
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    
    // 2. 核心公式：双重循环累加
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            // a[i] 和 b[j] 相乘，结果累加到 i+j 的位置
            res[i + j] += (a[i] - '0') * (b[j] - '0');
        }
    }
    
    // 3. 统一处理进位
    for (int i = 0; i < m + n - 1; i++) {
        if (res[i] >= 10) {
            res[i + 1] += res[i] / 10; // 进位给下一位
            res[i] %= 10;              // 保留个位
        }
    }
    
    // 4. 去除前导零（逆序数组中，高位在末尾）
    int len = m + n;
    while (len > 1 && res[len - 1] == 0) {
        len--; 
    }
    
    // 5. 转换回字符串并输出
    string ans = "";
    for (int i = len - 1; i >= 0; i--) {
        ans.push_back(res[i] + '0');
    }
    return ans;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

## 三、 代码逐行深度拆解

### 1. 为什么开 `m + n` 大小的数组？
对于两个大整数，位数分别是 $m$ 和 $n$。它们的乘积**最多**有 $m + n$ 位。
例如：最大的两位数 $99 \times 99 = 9801$（4 位数，$2 + 2 = 4$）。
所以 `vector<int> res(m + n, 0);` 是绝对安全的，不需要额外判断边界。

### 2. 核心公式 `res[i + j] += (a[i] - '0') * (b[j] - '0');`
*   因为我们把字符串**翻转**了，所以下标 `i` 实际上代表的是从低位数的第 `i` 位（即 $10^i$ 位）。
*   $a$ 的第 $i$ 位（代表 $10^i$）和 $b$ 的第 $j$ 位（代表 $10^j$）相乘，结果自然是 $10^{i+j}$ 位。
*   因此，它应该累加到结果数组的 `i + j` 位置上。这一步把所有中间乘积都算出来，暂时不管进位。

### 3. 进位处理 `res[i+1] += res[i] / 10; res[i] %= 10;`
双重循环跑完后，`res` 数组里的每个数字可能会大于等于 10（例如两位数乘两位数，中间位置累加后可能达到几十）。
在这里统一从低位向高位扫描，将超出 10 的部分进位给下一位。

### 4. 去除前导零 `while (len > 1 && res[len - 1] == 0) len--;`
因为 `res` 是逆序存储的（个位在 `res[0]`），所以高位在数组的末尾。我们需要从后往前剔除多余的 `0`。
注意这里的 `len > 1`，是为了防止结果是 `"0"` 的情况，如果结果是 0，我们至少要保留一个 `0` 输出。

## 四、 与“大数加法模拟乘法”的对比

*   **加法模拟法（之前你的思路）**：大数乘法 = 多次大数加法。为了算 $a \times 45$，先把 $a$ 加 4 次得到 $a \times 5$，再去算 $a \times 40$。
    *   **缺点**：极端情况下（比如乘以 9），要做 8 次大数加法。时间复杂度 $O(N \times M \times 10)$，效率低且代码长。
*   **标准模板法（当前思路）**：直接模拟乘法，双重循环。
    *   **优点**：时间复杂度 $O(N \times M)$，速度快，代码结构固定，不易出错，可扩展性强（以后做高精度阶乘、高精度幂都用得上）。

## 五、 ⚠️ 避坑指南

1.  **特判 0**：如果输入是 `0` 和 `0`，如果不加 `if (a == "0" || b == "0") return "0";`，去前导零的逻辑可能会返回空字符串，导致 WA。
2.  **`size_t` 和 `int` 混用**：在循环中反向遍历 `for (int i = m - 1; i >= 0; i--)` 时，`i` 必须是 `int` 类型，**千万不要用 `size_t`**，否则 `i >= 0` 永远成立，导致死循环和越界。
3.  **入参修改**：模板中对 `a` 和 `b` 做了 `reverse` 操作，这会直接修改传入的字符串。如果在 `main` 里后续还要用到原字符串，记得传参时用**值传递** `string a, string b`（模板中就是这么做的），而不是引用传递 `string& a`。
4.  **符号处理**：该模板仅适用于非负整数。如果题目包含负数，需要额外用 `bool` 记录符号位，计算绝对值乘积，最后补上负号。
