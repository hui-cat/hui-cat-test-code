
## 一、 核心问题：为什么要写 `n = n * a % 7`？

在处理指数增长（如求 $a^b$）或阶乘等极容易产生天文数字的题目时，**直接在最后对结果取模是不可行的，必须“边乘边取模”**。

### 1. 防止数据溢出（Overflow）
以本题为例，$a \le 100$，$b \le 10000$。
如果试图先计算 $a^b$ 再取模，即使 $a$ 仅为 2，$2^{10000}$ 也是一个约 3010 位的超级大数。
C++ 中最大的标准整型 `unsigned long long` 最大只能存储约 $1.8 \times 10^{19}$（20位数字）。强行计算会导致数据溢出，得到完全错误的结果。
通过每次乘法后立刻 `% 7`，变量 `n` 将永远被限制在 0~6 之间，从而杜绝溢出。

### 2. 数学原理：同余定理
根据数学上的同余定理，取模运算对加法和乘法具有分配律：
*   加法：$(a + b) \pmod m = ((a \pmod m) + (b \pmod m)) \pmod m$
*   乘法：$(a \times b) \pmod m = ((a \pmod m) \times (b \pmod m)) \pmod m$

因为题目只关心 $a^b \div 7$ 的余数，所以可以在每一次乘法时，把高位数截断（取模），保留余数继续参与后续运算，最终结果不变。

## 二、 代码执行过程推演（以 $a=3, b=2$ 为例）

*   初始化：`n = 1` (1 相当于乘法初始值，0 天后为星期日)
*   第 1 次循环 (`i = 1`)：`n = 1 * 3 % 7 = 3`
*   第 2 次循环 (`i = 2`)：`n = 3 * 3 % 7 = 9 % 7 = 2`
*   循环结束，`n = 2`，对应输出 Tuesday。

## 三、 相关知识点系统梳理

### 1. 取模运算的性质（竞赛必备）
*   **加法**：`(a + b) % p = (a % p + b % p) % p`
*   **减法**：`(a - b) % p = (a % p - b % p + p) % p`（注意 C++ 中负数取模结果仍为负，需 `+p` 转为正数）
*   **乘法**：`(a * b) % p = (a % p * b % p) % p`
*   **⚠️ 除法（重点避坑）**：**取模运算对除法没有分配律！** `(a / b) % p` 不能直接展开，必须使用**乘法逆元**（费马小定理 / 扩展欧几里得）来求解，这是后续进阶算法的重要内容。

### 2. 数据类型溢出（Overflow）
在算法题中，题目给定的数据范围通常是“警告”。遇到指数级增长（如 $a^b$）或阶乘（$n!$）时，必须立刻联想：**是否会导致数据溢出？是否需要取模？或者需要使用高精度算法？**
*   `int`：最大约 $2 \times 10^9$
*   `long long`：最大约 $9 \times 10^{18}$

### 3. 状态映射思想（星期映射）
星期日=0/7，星期一=1……星期六=6。
将逻辑状态映射为数字索引，在算法题和游戏开发中极其常见：
*   游戏开发：角色状态机（待机=0，跑动=1，攻击=2）
*   数组取模循环：`arr[i % n]` 实现环形数组或周期循环

### 4. 进阶优化：快速幂（Fast Exponentiation）
*   **当前解法时间复杂度**：$O(b)$。因为 $b \le 10000$，循环一万次可以接受。
*   **进阶场景**：如果未来遇到 $b \le 10^9$ 的题目，按当前的循环就会发生 **TLE（时间超限）**。
*   **解决方案**：利用二进制的思想，将指数 $b$ 拆解，使得时间复杂度降为 $O(\log b)$，这就是**快速幂**算法。这是大一下学期或大二必须熟练掌握的核心算法之一。

## 四、 ⚠️ 避坑指南

1. **初始值设定**：`n` 的初始值必须为 `1`，因为它是乘法累乘的初始状态。如果初始为 `0`，结果将永远为 `0`。
2. **特判除数取模**：若 `a` 恰好是 7 的倍数（如 7, 14），`a % 7 == 0`，此时 `n` 会变成 `0`，输出 `Sunday`，符合题目逻辑。
3. **大数取模不要用 `pow()`**：C++ 的 `pow()` 返回 `double` 类型，会丢失精度，且不能用于取模运算。必须使用循环或快速幂手写。
4. **有符号与无符号取模**：负数取模：`-1 % 7` 在 C++ 中结果是 `-1`，需要写成 `((-1 % 7) + 7) % 7` 才能得到正数 `6`。平时写代码要养成顺手加 `p` 的习惯。
