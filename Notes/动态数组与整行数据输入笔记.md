# 📘 C++ 算法竞赛：动态数组与整行数据输入全指南

## 一、 动态数组的初始化（`new` 与 `vector` 双轨制）

### 1. 为什么 `int array[m][n]` 会报错？
C++ 标准（C++11及以后）**不支持变长数组（VLA, Variable Length Array）**。虽然某些编译器（如 GCC）作为扩展允许通过编译，但这是一种极其危险的做法，极易导致栈内存溢出。因此，动态开辟内存（堆内存）是解决此问题的标准方案。

### 2. 方法一：使用 `new` 指针（手动内存管理，了解即可）

```cpp
int m = 3, n = 4;
// 第一步：分配行指针
int **array = new int *[m]; 
// 第二步：为每一行分配列内存（关键！）
for (int i = 0; i < m; i++) {
    array[i] = new int[n]; 
}
// 第三步：释放内存（顺序与分配相反）
for (int i = 0; i < m; i++) {
    delete[] array[i]; 
}
delete[] array; 
```
*(💡 缺点：写法繁琐，极易因忘记 `delete[]` 导致内存泄漏，因此在日常刷题中已被 `vector` 取代。)*

### 3. 方法二：使用 `vector`（⭐ 强烈推荐，OJ 首选）

#### 💡 基础用法：指定行列大小
这是最常用的初始化方式，相当于创建了一个 `m` 行 `n` 列的二维数组，并默认初始化为 `0`。

```cpp
#include <vector>
#include <iostream>
using namespace std;

int main() {
    int m = 3, n = 4;
    
    // 创建 m 行 n 列的二维数组，初始值默认全为 0
    vector<vector<int>> array(m, vector<int>(n)); 
    
    // 访问和修改：和普通二维数组完全一致
    array[0][0] = 1; 
    array[2][3] = 99;
    
    // 获取行数与列数
    int rows = array.size();       // rows = 3
    int cols = array[0].size();    // cols = 4 (注意：前提是第0行存在)
    
    return 0; // 不需要手动释放内存，程序结束自动销毁！
}
```

#### 🛠️ 进阶用法 1：动态添加行（不预先分配列）
在图的邻接表（Graph Adjacency List）中，我们往往不知道每一行会有多少数据，这时不需要提前指定列大小。

```cpp
// 创建一个包含 m 个空容器的二维数组
vector<vector<int>> graph(m); 

// 向第 0 行添加元素（相当于动态增加列）
graph[0].push_back(10);
graph[0].push_back(20);

// 向第 1 行添加元素
graph[1].push_back(30);

// 此时 graph 的形状可能是：
// graph[0]: [10, 20]
// graph[1]: [30]
// graph[2]: [] (空)
```
*💡 注意：这种“每行列数不同”的数组称为“锯齿数组（Jagged Array）”。在算法题中极其常见，例如存储图的边。*

#### 🛠️ 进阶用法 2：带权图的邻接表（存坐标或权重）
在图论中，我们经常需要存“点 + 权值”，可以用 `pair` 或结构体。

```cpp
// 相当于 vector 的二维数组，但每一行存的是 pair<int, int>
vector<vector<pair<int, int>>> adj(n + 1); 

// 添加一条从 u 到 v，边权为 w 的边
adj[u].push_back({v, w}); 
```

#### 🔄 遍历方式
```cpp
// 方法一：下标遍历（推荐，与数组一样直观）
for (int i = 0; i < array.size(); i++) {
    for (int j = 0; j < array[i].size(); j++) {
        cout << array[i][j] << " ";
    }
}

// 方法二：范围 for 循环（C++11 特性，更简洁）
for (const auto& row : array) {
    for (int val : row) {
        cout << val << " ";
    }
}
```

#### ⚠️ 内存结构与性能避坑
*   **不是连续内存**：`vector<vector<int>>` 底层并不是一整块连续的内存（像 `int arr[3][4]` 那样）。它是多个独立的 `vector` 组成的，行与行之间的内存不连续。这会导致 CPU 缓存命中率略低于原生的二维数组。
*   **OJ 建议**：对于 **10^5 x 10^5** 这种极其巨大的网格，`vector<vector<int>>` 的内存开销（每个 vector 对象本身占用 24 字节）和分配开销会很大，甚至导致 Memory Limit Exceeded (MLE)。此时应尽量用一维数组模拟二维（例如 `int arr[100000 * 100000]` 或者 `vector<int> arr(m * n)`）。

## 二、 整行数据的输入与初始化数组

### 场景 1：输入无空格连续数字（如 "999382"）

#### 方法 A：字符串读入法（⭐ 最推荐，最安全）
**适用**：数字超长（超过 `long long` 范围）、有前导零、要求正序处理。
**原理**：利用 ASCII 码，`'9' - '0' = 9`。

```cpp
string s;
cin >> s;           // 读入 "999382"
int arr[100005];    
int len = s.length();

for(int i = 0; i < len; i++) {
    arr[i] = s[i] - '0';  // 字符转数字的万能钥匙
}
```

#### 方法 B：数学拆解法（常规法）
**适用**：数字长度在 `long long` 范围内（通常 ≤ 10^18）。
**注意**：提取出的数字是**逆序**的，如需正序需用到 `reverse`。

```cpp
long long n;
cin >> n;
int arr[100005];
int len = 0;

while(n > 0) {
    arr[len++] = n % 10; // 取出最后一位
    n /= 10;             // 去掉最后一位
}
reverse(arr, arr + len); // 翻转成正序
```

#### 方法 C：`scanf` 宽度限制法（偏门但优雅）
```cpp
int arr[100005], len = 0;
// %1d 表示每次只读入1位整数，循环直到文件结束(EOF)
while(scanf("%1d", &arr[len]) != EOF) {
    len++;
}
```

### 场景 2：输入带空格的数字（如 "9 9 9 3 8 2"）
**直接交给 `cin` 自动跳过空格和换行：**

```cpp
int n;
int arr[100005];
int len = 0;
while (cin >> n) { // 读到无法继续读入（如换行符、文件结束）为止
    arr[len++] = n;
}
```

## 三、 ⚠️ OJ 避坑指南（血泪经验总结）

1. **字符 `'0'` 和整数 `0` 千万别搞混**：
   `arr[i] = s[i]` 会存入 ASCII 码（比如 57），**必须写成 `s[i] - '0'`** 才能存入真实数字（9）。
2. **数组开大一点**：
   切勿使用 `arr[n]` 动态长度（除非用 `vector`）。OJ 题目的长度可能达到 10^5 甚至 10^6，建议在全局（main 函数外）定义 `int arr[100005];`。
3. **`new` 和 `delete` 必须配对**：
   使用了 `new` 就一定要有对应的 `delete[]`。如果是二维数组，必须用 `for` 循环逐行 `delete[]`，最后再 `delete[]` 行指针。防止内存泄漏。
4. **二维数组的边界陷阱**：
   C++ 不会报越界错误。务必在递归或循环前，**先在函数开头写好边界剪枝**（如 `if (y < 0 || y >= m || x < 0 || x >= n) return;`），严防未定义行为（UB）引发灵异Bug。
5. **`vector` 的“行”和“列”翻转**：
   如果用 `vector<vector<int>> array(m, vector<int>(n))`，你的坐标系映射依然是 `array[y][x]`，这和用 `new` 是一模一样的。
6. **`vector` 的 `size()` 返回类型是 `size_t`（无符号整数）**：
   在 `for` 循环中，如果写 `for (int i = 0; i < v.size() - 1; i++)`，当 `v.size()` 为 0 时，`0 - 1` 会变成一个巨大的正数，导致循环越界崩溃。**推荐写成 `int size = v.size();` 后再进行循环。**
